# Vectrum for AEC logo assets

**Tower Cut is the only approved Vectrum for AEC mark** (selected October 2, 2026): a violet V with integrated building forms, no windows, and a clean junction between the central tower and the right arm of the V. Do not use retired product logos, the window variation, or a code-drawn monogram as the current identity.

| File | Status | Notes |
| --- | --- | --- |
| `vectrum-aec-logo-approved.png` | **Approved reference (source of truth)** | 1254 × 1254 PNG on a white background. |
| `vectrum-aec-logo-supplied.svg` | Supplied trace, not a production vector | Auto-traced from the PNG (VTracer 0.6.4). Includes an opaque `#FDFDFD` background and traced fills that are close to, but not exactly, the palette. Use only where the PNG cannot be; a clean transparent vector export has not been prepared. |

Import paths:

```ts
import logoPng from "@vectrum/brand/assets/vectrum-aec-logo-approved.png";
import logoSvg from "@vectrum/brand/assets/vectrum-aec-logo-supplied.svg";
```

New wordmark artwork, recolors, or a transparent/vector re-export require owner review before use (BRAND.md).
